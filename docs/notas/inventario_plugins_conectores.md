# Inventory of Claude plugins, skills and connectors for recording or transcribing meetings (state as of 2026-11-02)

## Which Claude integrations actually record, which only read recordings made elsewhere, and which only process text?

### Takeaway
Almost everything in the catalog only reads. No mainstream notetaker connector (Fathom, Fireflies, Otter, Granola, tl;dv, Read AI, Krisp, Circleback, Fellow, Grain, Tactiq, Zoom, Webex, Gong) lets Claude start a recording or send its bot. The items where Claude itself can start capture are few: three community plugins that send a cloud bot (MeetNotes, Meeting.ai, MeetStream), one Anthropic-verified desktop extension that records locally (Minutes), one paid local app with a "Record" permission (Meetily Pro), plus unlisted or developer MCP servers (Speak AI, Vexa, joinly, Meeting BaaS, Attendee). This user has none of the recording items installed, and already has only read-only routes (Fathom connected, others awaiting authorization).

### Cited Findings

#### Source key
- **[SP]** = output of the SearchPlugins tool, run 2026-11-02 (covers the "Anthropic Directory" and "Knowledge Work" catalogs; no public URL).
- **[REG]** = output of `mcp__mcp-registry__search_mcp_registry`, run 2026-11-02 (no public URL).
- **[STATUS]** = output of `session_connectors_status` for this user's session, run 2026-11-02 (no public URL).
- **[LOCAL]** = files in this user's installed plugin folder, `[carpeta local de plugins]`.
- Trust tier in plugin rows is the `publisher.tier` field in [SP] (`anthropic`, `partner`, `community`, all with basis `directory_review`). In connector rows, "Anthropic verified" appears only where I saw that label on the claude.com page. Those pages also warn to use connectors only from developers you trust, because Anthropic does not control the tools ([example](https://claude.com/marketplace/connectors/otter-ai)).
- "Has it" means this user's state in [STATUS] and [SP] `enabled`. Nothing was installed, connected or authorized, and no tool that reads the user's meeting content was called.
