# Grabar reuniones con Claude

Investigación al 2 de noviembre de 2026 sobre todas las formas de grabar reuniones con Claude, gratis y de pago, con guía paso a paso y una skill de actas en español de Chile.

**Sitio:** https://grabar-reuniones-claude.vercel.app

**Si eres otro Claude:** empieza por [CLAUDE.md](CLAUDE.md).

## Contenido

- [Guía paso a paso](docs/guia-paso-a-paso.md): cómo usar cada método y cómo confirmar que está grabando.
- [Informe completo](docs/informe.md): opciones, precios, conectores, legalidad en Chile y discrepancias entre fuentes.
- [Skill actas-reunion](docs/skill-actas-reunion.md): qué hace, resultados y pendientes. La skill está en [skill/actas-reunion](skill/actas-reunion).
- [Notas de investigación](docs/notas): fuentes y notas de trabajo, casi todas en inglés.

## Límites

Los precios y planes cambian: verifícalos antes de decidir. Ninguna herramienta se probó en una reunión real durante la investigación. Esto no es asesoría legal. Este proyecto no tiene relación con Anthropic, Apple ni los productos mencionados.

## Compilar el sitio

```bash
npm ci
npm run build
```

El resultado queda en `public/`.
